# Architecture -- seanjones.io portfolio App

## System Overview

The seanjones.io portfolio App is web application built with TypeScript and vue with scss. It provides the user with my skills, experience and provide the user with a sense of what I've accomplished in my career. The focus should be on performance over everything. The goal is to present this information as fast as possible with perfect lighthouse scores for performance, accessibility, best practices and SEO. The site should be completely responsive.
